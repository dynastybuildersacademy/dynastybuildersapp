☁ Monday.com Roster Sync

      

        Syncs all agents to the Agent Roster board (18411252280). Pull & Sync first pulls all existing items from Monday.com to build the ID map, then updates rows that exist and only creates genuinely new agents — no duplicates. Pull from Monday loads existing data without writing.
      

      

        
        
        
      

      

    

    

      
How Editing Works

      

        Edit in this page — Click the ✏️ edit button on any agent row in the Roster tab to open the edit modal. Change name, phone, email, role, PHP ID, upline, or license states, then click Save. Changes save to browser memory immediately.


        Sync to Monday.com — After editing, click Sync All to push the updated roster to Monday.com. Each agent row is matched by Agent ID and updated if found, or created if new.


        Permanent update (auth.js) — The AGENTS array in auth.js is the system source of truth. After editing agents here, copy the generated snippet from the Add Agent tab and update auth.js, then redeploy. Until you redeploy, edits live only in this session.

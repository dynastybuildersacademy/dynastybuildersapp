Dynasty Builders // Follow-Up Sequences

The 3-7-30 Method

Triggered automatically when a prospect completes the intake form on client.html or brochure.html.
Delivered by Zapier. Variables like {{fname}} auto-fill from the contact captured at intake.
Why 3-7-30, not "follow up twice and give up"

Most people don't buy on the first or second touch — they need more information first. This sequence never says "buy my thing" outright. Every message is built to stand alone as something worth reading, even for someone who never converts. Think value sequence, not follow-up.

PHASE 1 · DAYS 1-3 The Spark
One touch a day. Best case study, then best transformation, then your biggest industry insight. This is where you earn the right to keep emailing them.
PHASE 2 · DAYS 4-10 Objection Removal
One touch every other day. Each message is a reverse FAQ — it names ONE specific fear or hesitation and answers it with proof, not pressure.
PHASE 3 · DAYS 11-40 Value Rotation
Two touches a week, alternating success story and industry insight. Each one valuable enough to stand alone — "damn, this is good stuff, even if I don't buy."

Zapier Setup

Recommended: Table + Daily Schedule (scales to unlimited leads)

One small Zap enrolls leads. A second Zap runs once a day, checks how many days each lead has been in the sequence, and sends the matching message. Nothing breaks if you edit copy mid-sequence, and it doesn't hit per-lead step limits the way a giant Delay chain does.
Zap A — Enroll the Lead
1
Trigger: Webhooks by Zapier → Catch Hook. This replaces the Make.com hook currently wired into your intake forms.
2
Filter: continue only if the payload includes fname and email.
3
Action → Zapier Tables: Create Record in a table called Follow-Up Queue with columns: name, email, phone, agent_id, agent_name, agent_phone, funnel (client/recruit), enrolled_date (today), last_day_sent (0), status (active).
Zap B — Daily Dispatch
1
Trigger: Schedule by Zapier → Every day, ~8:00 AM local.
2
Action → Zapier Tables: Find Records where status = active.
3
Action → Looping by Zapier, once per record found.
4
Action → Formatter (Numbers): days_since = TODAY − enrolled_date.
5
Action → Paths by Zapier, branching on days_since + funnel:
• Days 1, 2, 3 → Phase 1 message for that day and funnel
• Days 4, 6, 8, 10 → Phase 2 objection email/SMS for that day and funnel
• Day ≥ 11, every 3rd/4th day (≈ twice weekly) → Rotation Library, alternating Success Story / Industry Insight
• Day > 40 → set status = graduated (sequence ends; agent takes over personally)
6
Each path's final step is Gmail: Send Email (or Twilio: Send SMS for SMS-tagged touches) using the copy below, then Zapier Tables: Update Record to set last_day_sent.
Migrating from Make.com: your intake pages (client.html, brochure.html, opportunity.html, recruit.html, etc.) currently POST to a Make.com webhook. Swap that URL for the Zap A Catch Hook URL once it's live — same JSON payload, no other changes needed.
Simpler alternative — Delay Chain
If lead volume is low enough that per-lead Zaps are fine: one Zap per funnel, Catch Hook → Gmail (Day 1) → Delay 1 day → Gmail (Day 2) → Delay 1 day → Gmail (Day 3) → Delay 1 day → Gmail/SMS (Day 4)… continuing the same pattern through Day 10, then Delay → Send pairs every 3-4 days for the rotation phase. Simple to build, but editing the Zap mid-flight changes future sends for everyone already inside it — the Table + Schedule pattern above avoids that.

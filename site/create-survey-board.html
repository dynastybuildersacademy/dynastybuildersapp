What This Creates

This will create a dedicated DBA — Financial Surveys board in your Monday.com workspace with all the columns needed to capture survey submissions automatically. Once created, the board ID is saved and all future survey submissions will write to it.

Columns That Will Be Created
first_nameText — Prospect first name
last_nameText — Prospect last name
phonePhone — Mobile number
emailEmail — Email address
profileText — Financial profile type
budgetNumbers — Monthly budget ($)
goalsLong Text — Financial goals
referring_agentText — Agent who shared the survey
sourceText — Lead source
survey_dateDate — Date submitted
best_timeText — Best follow-up time
healthText — Health rating
tobaccoText — Tobacco use
notesLong Text — Additional notes
statusStatus — Lead status (New / Contacted / Appointed / Closed)
